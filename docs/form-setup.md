# フォームの受け口の設置（Google スプレッドシート＋Apps Script）

サイトの3つのフォーム（無料相談・代理店の資料請求・代理店お申込み）は、送信内容を Google Apps Script（GAS）の受け口に送ります。
受け口は、届いた内容を **スプレッドシートにフォームごとのシートで保存** し、**info@kintoun-m.com に通知メール** を送ります。

受け口のプログラムは `tools/gas/form-receiver.gs` です（サイトには公開されません）。

## 設置の手順（10分ほど）

1. 会社の Google アカウントで Google スプレッドシートを新しく作る（名前の例：「Table フォーム受付」）
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身をすべて消し、`tools/gas/form-receiver.gs` の中身を貼り付けて保存
4. 上の関数の選択欄で `testSend` を選んで「実行」
   - 初回は「承認が必要です」と出るので、アカウントを選んで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全でないページ）に移動」→「許可」）
   - info@kintoun-m.com にテストの通知メールが届き、スプレッドシートに「無料相談」シートができれば成功
5. 右上の「デプロイ」→「新しいデプロイ」
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
   - 「デプロイ」を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー
6. `tools/data.mjs` の `formEndpoint: ""` にその URL を入れて、GitHub に送る（Cloudflare が自動で公開）

## 設定を変えたいとき（form-receiver.gs の先頭）

- `NOTIFY_TO`：通知メールの宛先。カンマ区切りで複数にできる
- `AUTO_REPLY`：お客さまに「受け付けました」メール（送信内容の控えつき）を自動で返す。止めるときは `false`
  - 差出人は受け口を設置した Google アカウントになるので、会社のアカウントで設置してから有効にする

プログラムを直したときは「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」で更新する（URL は変わらない）。

## 迷惑送信の対策

- 人には見えない入力欄（`website`）に何か入っていたら、保存も通知もしない
- 同じメールアドレスから60秒以内に続けて届いたものは1件として扱う
- 数式として解釈されそうな値（先頭が `=` など）は、文字のまま保存する
