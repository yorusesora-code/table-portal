# トップKV「島」イラスト 発注仕様書

トップページのファーストビュー（`src/pages/index.html` の `.kv`）で使う、4つの島のイラストの仕様です。
いまはインラインSVG（仮）で描いていますが、この仕様どおりの画像に差し替えればそのまま動きます。

## 全体

| 項目 | 指定 |
|---|---|
| 画風 | アイソメトリック（斜め上から見下ろす）の線画＋フラット塗り。hellocycling.jp のトップに近いトーン |
| 主線 | オレンジ `#f0923a`、線幅は画像幅400px換算で2px相当。線の太さは全島で統一 |
| 塗り | 白 `#ffffff`、淡い黄 `#fff6d8` `#ffecb8` `#ffe08d`、黄 `#fabe00`、島の側面 `#ffd25e`。**この6色以外は使わない**（肌色 `#ffd9b8` のみ例外） |
| 背景 | 透過 |
| 文字 | イラスト内に文字は入れない（「OPEN」「¥0」などはこちらで重ねる） |
| 影 | 島の下の影は別ファイルにする（浮き上がる演出で影を残すため） |

## 納品してほしいファイル（島ごと）

元サイトと同じく「動かない部分」と「動く部分」を分けてください。

1. `xxx_base.webp` … 動かない部分すべて（幅1600px以上、透過WebPまたはPNG）
2. `xxx_anim.webp` … 動く部分だけのアニメーション（透過のアニメWebP。なければAPNG/GIF可）。base と同じキャンバスサイズ・同じ座標
3. `xxx_shadow.png` … 島の下の影
4. 可能なら AI/PSD のレイヤー付き元データ

## 島ごとの内容

| ファイル名 | 島 | 描くもの | 動く部分（anim） | 形 |
|---|---|---|---|---|
| `web` | HPがないお店（Table Web） | 新しい小さな飲食店（日よけ・扉・窓・黒板メニュー）、店主がスマホを見ている、まだ中身のない点線のブラウザ枠 | 周回道路を走るデリバリーのバイク、煙突の湯気、「OPEN」の吊り看板の揺れ | 丸い島（楕円） |
| `shift` | HPが古いお店（Table Shift） | 古いブラウン管PCに色あせたHP、矢印の先に新しいスマホのHP、考えている店主 | 矢印の往復、上へ抜けていく「¥」コイン | ひし形の島 |
| `plan` | 月額0円（中央） | 大皿とクロッシュ（銀のふた）。ふたの表面は無地（「¥0」はこちらで重ねる）、上に旗を持つ人 | ふたの周りを回るフォーク、旗のなびき | 円形・島の中で一番大きい |
| `camp` | デリバリー割引 | 街の地図（道・家・お店）、黄色いルート、ピン3本 | ピンの弾み、ルートを往復する配達員 | ひし形の島 |

空のレイヤー（雲・飛行機・気球）は現行のSVGのままで構いません。

## 差し替え手順（こちらの作業）

各島の `<svg>` を次の構成に置き換えます。クリック範囲は透明な図形 `.hit` を島の形に合わせて残します。

```html
<a class="stage__inner" href="/service/table-web/">
  <svg viewBox="0 0 400 340"><ellipse class="hit" cx="200" cy="200" rx="190" ry="140"/></svg>
  <img src="/assets/img/kv/web_base.webp" alt="">
  <img src="/assets/img/kv/web_anim.webp" alt="">
</a>
```
